Sheet music import (experimental)

Photograph or scan a page of music, let a model read it, check what it saw, then take the result into My Song Writer as a backup file.

1. Pages

One image per page, in order. Big photos are shrunk before they are sent. PDFs are not accepted yet.

2. Read the pages

The key is stored in this browser's localStorage and sent straight to the API from this page. Fine for a private test, not for a shared page: see the README.
